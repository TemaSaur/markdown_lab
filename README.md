# Лабораторная работа: Работа с форматом Markdown

## Теоретическая часть

**Markdown** — это облегчённый язык разметки, который преобразует текст в HTML. Используется для создания документации, README-файлов, статей и заметок.

### Основные элементы синтаксиса

- `#` — заголовки (от # до ######)
- `**текст**` — жирный шрифт
- `*текст*` — курсив
- `~~текст~~` — зачёркнутый текст
- `` `код` `` — встроенный код
- `[текст](ссылка)` — гиперссылка
- `![alt](путь)` — изображение
- `-` или `*` — маркированный список
- `1.` — нумерованный список

### Пробелы и переносы строк в Markdown

**ВАЖНО!** Markdown имеет особые правила обработки пробелов и переносов:

1. **Один перенос строки** (Enter один раз) — игнорируется, текст склеивается в один абзац:
   ```
   Это первая строка
   Это вторая строка
   ```
   Результат: "Это первая строка
   Это вторая строка"

3. **Два пробела в конце строки + Enter** — создаёт мягкий перенос (переход на новую строку):
   ```
   Это первая строка••
   Это вторая строка
   ```
   (где •• — два пробела)

4. **Пустая строка** (Enter два раза) — создаёт новый абзац:
   ```
   Это первый абзац

   Это второй абзац
   ```

5. **Несколько пробелов подряд** — схлопываются в один пробел при отображении

6. **Для принудительного переноса** можно использовать HTML-тег `<br>`:
   ```
   Первая строка<br>
   Вторая строка
   ```

### Использование эмодзи в Markdown

Markdown поддерживает эмодзи двумя способами:

1. **Прямая вставка эмодзи** (копирование символа):
   ```
   Привет! 👋 Это круто! 🎉
   ```

2. **Использование кодов эмодзи** (поддерживается на GitHub, GitLab и других платформах):
   ```
   :smile: :heart: :rocket: :computer:
   ```
   Результат: :smile: :heart: :rocket: :computer:

**Полный список эмодзи с кодами:**
- [Emoji Cheat Sheet](https://github.com/ikatyang/emoji-cheat-sheet)
- [Emojipedia](https://emojipedia.org/)
- [Gitmoji](https://gitmoji.dev/) — эмодзи для коммитов

### Задание 1: Создание заголовков

Создайте иерархию заголовков:
- Заголовок 1 уровня: "Мой первый Markdown-документ"
- Заголовок 2 уровня: "О себе"

### Задание 2: Форматирование текста

Напишите абзац о себе (минимум 5 предложений), используя:
- **Жирный текст** для выделения важной информации (минимум 2 раза)
- *Курсив* для акцентов (минимум 2 раза)
- ~~Зачёркнутый текст~~ для примера (минимум 1 раз)
- `Встроенный код` для технических терминов (минимум 1 раз)

**Пример:**
```
Меня зовут **Иван Петров**, я студент колледжа. Изучаю *программирование* и *веб-разработку*. ~~Раньше не знал Markdown~~, но сейчас активно его использую. Мой любимый язык — `Python`. В будущем хочу стать **специалистом по Data Science**.
```

2. Текст с мягким переносом (используя два пробела + Enter)
3. Текст с новым абзацем (через пустую строку)

Подпишите каждый пример заголовком третьего уровня.

### Задание 5: Ссылки и изображения
